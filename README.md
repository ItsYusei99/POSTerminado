# POS Universal — Sistema punto de venta

Sistema de **punto de venta (POS)** completo en un solo archivo HTML, sin paso de compilación.

## Características

- **Venta:** buscador, filtro por categoría, cuadrícula de productos y carrito con subtotal, impuestos y total.
- **Inventario:** tabla de productos con alta, edición y eliminación (modal).
- **Historial y reportes:** tickets guardados, total de ventas y conteo de tickets.
- Interfaz con Tailwind CSS (vía CDN) y datos persistidos en el navegador.

## Uso

1. Abre `index.html` en tu navegador (requiere internet para cargar Tailwind y las fuentes desde CDN).
2. Usa las pestañas **POS**, **Inventario** e **Historial** del encabezado.

## Estructura

```
index.html   # app completa (HTML + CSS + JS)
```
